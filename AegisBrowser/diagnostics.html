AEGIS BROWSER / LOCAL DIAGNOSTICS

What this browser exposes

This embedded page reads browser properties locally. It makes no network requests and stores no report. Values are observations, not an anonymity score. Profiles separate stored browsing data; they do not change your device or network identity.

Supported secure same-origin camera, microphone, location and notification requests use Chromium consent prompts. Other permissions, screen capture and downloads are denied. This page requests no permissions.

Local fingerprint exposure audit

This checks which browser APIs are present, without creating a fingerprint hash, requesting permissions, or sending data anywhere. Availability does not mean a site has actually accessed an API, and the report is not an anonymity or security-bypass score.

Privacy settings can block some network resources, including matching rules when a site is unknown if you opt in. They do not hide or change the browser APIs shown here, and some network paths are outside the filter.

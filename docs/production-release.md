# Production release assessment

> **Historical assessment for RC1 commit `e610ac5b837093975e54457b0808f561046302cb`.** References below to .NET 8, manual acceptance and the RC1 ZIP apply to that earlier artifact, not automatically to a later package. For the current package, read `VERSION.txt` and `PORTABLE-CANDIDATE.md`; use its own CI evidence and checksum. Both releases remain NO_GO until their separate gates pass.

**Decision: NO GO.** RC1 is a test candidate, not an approved production release. The self-contained package includes .NET 8, whose standard Microsoft support ended on November 10, 2026. The pinned Chromium 154 predates subsequent Chrome security fixes, including the critical CVE-2026-110922 and the exploited CVE-2026-125350; applicability and any CEF-specific backports must be verified rather than assumed. The pinned CefSharp binding initializes CEF with `no_sandbox = true`, and the application does not override it. This violates the release requirement for an enabled Chromium sandbox. Resolve these gates with a supported, security-reviewed runtime and independently verified sandbox configuration before distributing for production use.

Sources: [Microsoft .NET lifecycle](https://learn.microsoft.com/en-us/lifecycle/products/microsoft-net-and-net-core), [Google October 2026 security update](https://chromereleases.googleblog.com/2026/10/stable-channel-update-for-desktop_01886704284.html), [Google November 2026 security update](https://chromereleases.googleblog.com/2026/11/stable-channel-update-for-desktop_018223192.html), [pinned CefSharp settings](https://github.com/cefsharp/CefSharp/blob/ec1027a/CefSharp.Core.Runtime/CefSettingsBase.h), [pinned CefSharp initialization](https://github.com/cefsharp/CefSharp/blob/ec1027a/CefSharp.Core.Runtime/Cef.h), and [pinned CEF sandbox requirements](https://github.com/chromiumembedded/cef/blob/14c5a089e8452874cb1a556dc3fde26ed2d87723/docs/sandbox_setup.md).

The existing RC1 is a self-contained Windows x64 ZIP, not an installer. Extract into a new application folder and run `AegisBrowser.exe`; use `--profile=NAME` for a named profile or `--profiles` to open the manager. Profile data is separate under `%LOCALAPPDATA%\AegisBrowser\Profiles`. Do not overwrite or delete those directories during an application update.

Before an upgrade, close the browser and keep a backup of profile data and the known-good previous application ZIP and its SHA-256. Verify the new ZIP against the checksum and source commit published by its CI run before extraction. For rollback, close the browser and launch the previous application from its separate folder; do not delete browsing data. Backups should be restored only after assessing whether the newer browser changed a profile format. No backward compatibility across Chromium versions is guaranteed.

Privacy settings are available from the Privacy toolbar action. Third-party cookie blocking, WebRTC UDP restriction, WebGL/remote-font restriction and viewport letterboxing are opt-in and may break sites; settings that say restart require a profile restart. Cookie clearing is not included. OffscreenCanvas WebGL in tested page and worker contexts remains observable. Full fingerprint resistance, anonymity and system-wide network containment are not established. Required-proxy profiles fail closed, and the historic SOCKS timeout root cause remains inconclusive. The user-reported 8/8 desktop acceptance applies to RC1 commit `e610ac5b837093975e54457b0808f561046302cb`, not untested later binaries.

The verified RC1 artifact is linked from [its Windows push run](https://github.com/roshan-pandit1/AegisBrowser/actions/runs/43857082897); its inner ZIP SHA-256 is `449569e2edbf44d5443231d03808c30da0226f71a0f0fead9069838b53a9884d`. The RC1 executable is unsigned; Windows may display an unknown-publisher warning. Do not treat a checksum as an authenticity signature. For a later build, use that build's own CI checksum and commit, not this RC1 hash. Do not publish a production build until signing, dependency notices, security support and release gates have been reviewed.
